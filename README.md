 Campus Attendance Tracker
A simple web app to help students track subject-wise attendance and check if they meet the 75% requirement.
Features
- Add subject with total classes and attended classes
- Auto calculates attendance percentage
- Shows "Safe " or "Low " status
- Data saves in browser using localStorage
- Clean responsive UI
Tech Stack
HTML5, CSS3, JavaScript
How to Use
1. Enter Subject Name, Total Classes, Classes Attended
2. Click Add
3. View your attendance % instantly
